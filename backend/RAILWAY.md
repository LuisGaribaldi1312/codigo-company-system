# Railway.app Configuration
# This file helps configure Railway.app deployment for Código Company backend

## Environment Variables (configure these in Railway.app dashboard)

### Required Variables
DB_HOST=containers-us-north-1.railway.app
DB_PORT=5432
DB_NAME=railway
DB_USER=postgres
DB_PASSWORD=[generated by Railway PostgreSQL plugin]

### Authentication
JWT_SECRET=[generate a strong secret: openssl rand -base64 32]

### Server
PORT=$PORT  (Railway injects this automatically)
NODE_ENV=production

### Supabase (for photo storage)
SUPABASE_URL=https://[your-project].supabase.co
SUPABASE_ANON_KEY=[public anon key]

## Deployment Steps

1. Fork/Clone this repository
2. Create account on [Railway.app](https://railway.app)
3. Create new project → "Deploy from GitHub Repo"
4. Select this repository
5. Go to "Variables" tab and add the environment variables above
6. (Optional) Add PostgreSQL plugin: Settings → Plugins → PostgreSQL
7. The app will auto-deploy on push to `main` branch

## Build Command
```
npm install
```

## Start Command
```
node src/app.js
```

## Health Check
The app will be available at: https://[your-project]-backend.up.railway.app/health
