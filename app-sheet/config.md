# AppSheet Configuration File

## Overview
This file documents the AppSheet configuration for the Código Company mobile application.

## App Requirements

### 1. Authentication
- Use JWT authentication token generated by backend
- Store tokens securely in device Keychain/Keystore
- Auto-refresh tokens every 24h

### 2. Offline Mode
- All data synced to local device
- Works without internet connection
- Auto-sync when connection restored

### 3. Photo Capture
- Max size: 1MB per photo
- Auto-compression enabled
- GPS coordinates captured
- Evidence types: antes, durante, despues, plaga, area_tratada, etc.

### 4. Service Workflow
1. Técnico views assigned services
2. Técnico starts service (estado: en_proceso)
3. Técnico captures photos (evidencias)
4. Técnico completes service (estado: finalizado)
5. Auto-sync to backend

### 5. API Connector Settings
- Base URL: https://api.codigocompany.com
- Auth header: Authorization: Bearer <access_token>
- Endpoints:
  - GET /api/tecnicos/mis-servicios
  - GET /api/servicios/:id
  - PUT /api/servicios/:id/estado
  - POST /api/evidencias
  - GET /api/evidencias/servicio/:servicioId

### 6. Sync Configuration
- Sync interval: Auto-sync on network change
- Conflict resolution: Last write wins (timestamp based)
- Retry logic: Exponential backoff

### 7. Security Settings
- Biometric auth enabled
- App lock after 5 minutes of inactivity
- Clear data on logout
- Encrypted local storage

## Tables Synced with AppSheet

### servicios
- Columns: id, cliente_nombre, titulo, direccion, fecha, hora, estado, tipo_servicio, plaga_nombre
- Filter: tecnico_id = CURRENT_USER()
- Sort: fecha DESC

### evidencias
- Columns: id, servicio_id, foto_url, tipo_evidencia, fecha, hora, observaciones
- Auto-sync: On network change
- Photo compression: Enabled (target: 1MB)

### clientes
- Columns: id, nombre, empresa, telefono, whatsapp, direccion
- Read-only for técnico (from servicios view)

### tecnicos
- Columns: id, nombre, foto_url, zona, especialidades
- Read current technician profile
